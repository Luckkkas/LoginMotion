LoginMotion 

Uma tela de login moderna e animada, com tema visual verde, efeitos de fundo e uma interface minimalista.

✨ Funcionalidades

- Fundo com efeitos animados.
- Interface moderna e minimalista.
- Campo para nome de usuário.
- Campo para senha.
- Link para recuperação de senha.
- Link para cadastro de usuário.
- Layout adaptável à janela do navegador.

🛠️ Tecnologias utilizadas

- HTML5
- CSS3

📂 Estrutura do projeto

LoginMotion/
│
├── index.html
└── style.css

🚀 Como executar o projeto

1. Clone este repositório:

git clone https://github.com/SEU-USUARIO/LoginMotion.git

2. Abra a pasta do projeto.
3. Execute o arquivo "index.html" no navegador.

🎨 Sobre o projeto

O LoginMotion é um projeto Front-end desenvolvido com o objetivo de praticar HTML e CSS, explorando a criação de interfaces modernas, animações e efeitos visuais.
